# Fisio Barbara Man — O Percurso Doméstico

Site institucional e experiência interativa de fisioterapia vestibular, prevenção de quedas e reabilitação de autonomia no ambiente domiciliar para a fisioterapeuta **Barbara Man**.

## 🌿 Conceito & Experiência
- **Scroll Coreografado:** Narrativa visual do trajeto doméstico (quarto, corredor, escada e saída para o mundo).
- **Atos de Recuperação:** Seções sincronizadas com GSAP ScrollTrigger para explicar VPPB (vertigem posicional paroxística benigna), prevenção de quedas e osteopatia domiciliar.
- **Acessibilidade & Design Inclusivo:** Cores com alto contraste em conformidade WCAG AAA/AA, tipografia fluida e suporte completo a `prefers-reduced-motion`.

## 🛠️ Tecnologias Utilizadas
- **HTML5 Semântico:** Estruturação orientada a SEO e leitores de tela.
- **CSS Moderno / Design Tokens:** Paleta orgânica, tipografia Instrument Serif & Instrument Sans, sem frameworks pesados.
- **JavaScript & GSAP:** ScrollTrigger para coreografia tátil e suave.

## 🚀 Como Executar Localmente
Como se trata de um projeto estático, basta abrir o arquivo `index.html` em qualquer navegador ou servir localmente:

```bash
# Com npx serve ou Live Server
npx serve .
```
